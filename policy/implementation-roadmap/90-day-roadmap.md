# 90-Day Integration Roadmap (Planning Targets)

- **Days 1–15:** Establish integration charter, register six projects, map existing repositories/datasets, identify ownership and publication permissions. *(Phase 1 & 2 initial execution)*
- **Days 16–30:** Refine common data dictionary, metadata schemas, source provenance standards, and integration contracts.
- **Days 31–45:** Assess project dataset compatibility, identify missing indicators, expand synthetic integrated datasets, run validation tests.
- **Days 46–60:** Develop cross-project analytical notebooks (Modules 01–08), test indicator comparability.
- **Days 61–75:** Build policy intelligence register (`P1`–`P5`), develop public value evaluation framework, prepare policy options.
- **Days 76–90:** Prepare integration report, static dashboard prototype, policy brief drafts, and approved publication candidates (subject to Human Approval Gates 4, 5, 10).
