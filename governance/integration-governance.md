# Integration Governance & Human Approval Gates

## Project Sovereignty
Each of the six projects (`P01`–`P06`) remains independently governed. Integration **does not** transfer ownership, authorization, or publication rights between projects.

## Logical Multi-Agent Roles (12 Agents)
1. Chief Integration Orchestrator (maintains project registry, task registry, dependency map, approval gates, audit logs, version history, quality scores)
2. Project Coordination Agent
3. Data Architecture Agent
4. Source Provenance Agent
5. Legal Verification Agent
6. Statistical Comparability Agent
7. Cross-Project Research Agent
8. Policy Intelligence Agent
9. Public Value Evaluation Agent
10. Data Governance Agent
11. Quality Assurance Agent
12. Publication Agent

**Hard Separation of Duties:** Agents cannot approve their own outputs. No agent can authorize publication or institutional action.

## Mandatory Human Approval Gates (10 Gates)
Human approval is strictly required before:
1. Integrating datasets with unclear ownership.
2. Accessing restricted information.
3. Changing project methodologies.
4. Publishing comparative findings.
5. Publishing rankings or composite indices.
6. Making legal conclusions with material consequences.
7. Contacting institutions on behalf of the initiative.
8. Making public institutional representations.
9. Spending money.
10. Publishing any integrated dataset.
