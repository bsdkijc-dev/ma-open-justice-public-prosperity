# Source Provenance Standards

Every integrated record must trace back to:
- `source_project` (`P01`–`P06`)
- `source_institution` (e.g., Mahkamah Agung RI, BPS, Kemendesa PDTT, BPHN)
- `original_source_reference` (document title, regulation number, or official URL)
- `retrieval_date` (ISO 8601)
- `publication_class` (`P1`–`P5`)
- `validation_status` (`VERIFIED`, `PENDING_HUMAN_REVIEW`, `SYNTHETIC`, `UNVERIFIED`)
