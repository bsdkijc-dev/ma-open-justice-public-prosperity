# Contributing Guidelines

1. **Independence & Non-Endorsement:** Never imply official endorsement by Mahkamah Agung RI or any Indonesian government institution.
2. **Ownership Preservation:** Do not copy external project repositories or overwrite original project datasets. Reference approved datasets via `architecture/integration-contracts.md`.
3. **Human Approval Gates:** All 10 gates in `governance/integration-governance.md` require explicit human sign-off before execution.
4. **Validation:** Every PR must pass `python3 -m unittest discover -s tests -v`.
